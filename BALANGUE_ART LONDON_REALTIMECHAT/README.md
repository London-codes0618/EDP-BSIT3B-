# Zero - Realtime Chat
Author: Art London Balangue | Final Activity: Realtime Application

Features: multiple chat rooms, live online list, typing indicator, emoji reactions, modern dark glass UI.
Tech: Node.js (no external packages) + Server-Sent Events.

## Run
1. Install Node.js 18+
2. `npm start`
3. Open http://localhost:3000 in two tabs, use different names, and chat.
(For other devices on the same Wi-Fi, open http://YOUR-PC-IP:3000)
